# Installation & Setup

Install Back in Stock from the Craft Plugin Store or with Composer.

## Craft Plugin Store
Open **Plugin Store** in the Craft control panel, search for **Back in Stock**, and select **Try**.

## Composer
You can also add the package to your project using Composer and the command line.

1. Open a terminal and go to the Craft project.

```shell
cd /path/to/project
```

2. Require the package and install the plugin.

```shell
composer require verbb/back-in-stock && php craft plugin/install craft-commerce-back-in-stock
```
